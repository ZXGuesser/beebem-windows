Joysticks and Game Controllers

BeebEm supports joysticks and game controllers via XInput and DirectInput, connected to the emulated BBC Micro's "analogue in" socket. Use the Options → Select Joystick… menu item to configure the input device.

The dialog box shows a list of the controllers that have been detected. Only one controller can be used at a time, mapped to the Beeb's analog input channels 0 (X direction) and 1 (Y direction). Note that the same game controller may appear twice in the list, as both an XInput and a DirectInput device.

Select None to switch joystick support off.

For XBox controllers, the left stick and the D-pad are both enabled. Buttons A, B, X, and Y are all mapped to the joystick 0 fire button.

Select Analogue Mousestick to enable the mapping of mouse position to analogue Beeb joystick position. This allows you to use the mouse as a joystick. The left mouse button controls the joystick 1 fire button and the right mouse button controls the joystick 2 fire button.

Select Digital Mousestick to enable the mapping of mouse movements to digital Beeb joystick movements. The left mouse button controls the joystick 1 fire button and the right mouse button controls the joystick 2 fire button.

Press the Refresh button to update the list of avaialable input controllers, e.g., after plugging a joystick or game controller into the host PC.

Note that the Basic Hardware Only option disables the Analogue to Digital emulation, so this must be switched off if you want to use a game controller. See the Menu Options for more information.
